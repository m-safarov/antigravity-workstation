# MCP дар setup-и ҳозира

Installer launcher ва argument-ҳои сервери асосии [active.template.json](../config/mcp/active.template.json) (`chrome-devtools-mcp`)-ро нав мекунад. Credential-ҳои шахсӣ аз env/headers ва ҳолати enable/disable нигоҳ дошта мешаванд; env-и кӯҳнаи бе credential аз сервери идорашаванда тоза мешавад. Серверҳои шахсии дигар нигоҳ дошта мешаванд. Credentials ба repo ворид намешаванд. Конфиги асосӣ launcher-и маҳаллии ҳозираро истифода мебарад: `node.exe` → `~/.gemini/config/mcp-runtime/node_modules/`. Installer dependency-ро аз [package lock](../resources/mcp-runtime/package-lock.json) насб мекунад ва версия ва entrypoint-ро месанҷад; `node_modules` ба GitHub дохил намешавад.

| Server | Чӣ талаб мекунад | Ҳолати template |
|---|---|---|
| `chrome-devtools-mcp` | Node/npm; runtime-и pinned ва browser-и дастрас | Definition илова мешавад |

Насб шудани definition ҳанӯз маънои пайваст шудан ё кор кардани tool-ро надорад. Насби тозаи runtime-и Node ва `initialize` + `tools/list`-и он санҷида шуд: Chrome DevTools — 30 tool. Authorization-и account ва иҷрои ҳамаи ин tools алоҳида санҷида мешаванд. Баъди Reload Window дар Antigravity → Manage MCP Servers сервер, tools ва як амали read-only-ро санҷ. Серверҳои кӯҳнаи `docker-mcp`, `github-mcp-server`, `gsd` ва `sequential-thinking`-и setup-owned аз template хориҷ шудаанд, зеро Antigravity IDE 2.8.0 тафаккури бисёрсатҳа (Thinking) ва банақшагириро худаш иҷро мекунад. Аз Setup 3.13.0 update нусхаи setup-owned-и `sequential-thinking`-ро баъди backup тоза мекунад ва танҳо сервери шахсиро (агар корбар худаш дигар launcher гузошта бошад) нигоҳ медорад. Docker ва GitHub token барои `chrome-devtools-mcp` лозим нестанд.

Bootstrap-и [README](../README.md#quick-start) бо `--auto-approve` иҷро мешавад: native terminal/artifact Always Proceed ва MCP Allow ҳангоми IDE-и пӯшида ё баъди shutdown-и одӣ татбиқ мешаванд. MCP Ask/Deny-и қаблӣ бо сиёсати умумии `mcp(*) Allow` иваз мешавад; command/file deny-ҳои дигар нигоҳ дошта мешаванд. Барои нигоҳ доштани ҳамаи approvals installer-ро дастӣ бо `--skip-permissions` иҷро кун. [Status ва rollback](AGENT-AUTOMATION.md). Барои MCP-и нав account login/authorization алоҳида лозим аст. Дар баъзе версияҳои Antigravity native MCP Refresh метавонад lifecycle error диҳад; [Stability helper](STABILITY.md) танҳо reconnect-и идорашавандаро пешниҳод мекунад.
