# Расширения и настройки

[Установка и обновление](../README.md#quick-start). Полный каталог содержит 25 расширений (20 из галереи и 5 своих VSIX, включая Jelly Cursor). Существующие посторонние расширения сохраняются; команды main не устанавливают неопубликованную ветку.

Автоимпорт экспортов библиотек выполняет **встроенная служба JavaScript/TypeScript**. Установи библиотеку в проект, открой файл JS/TS/JSX/TSX, начни имя экспорта и нажми **Ctrl+Space**. Выбери вариант с нужным пакетом и нажми Enter — редактор добавит import. Пакету нужны корректные exports/типы; настройки не могут создать отсутствующие экспорты.

Настройки набора находятся в [settings.json](../config/settings.json), клавиши — в [keybindings.json](../config/keybindings.json), список расширений — в [extensions.json](../config/extensions.json). Auto Save работает после паузы 1000 мс; форматирование использует Prettier и уважает `.editorconfig` проекта. Конфигурация Prettier самого проекта имеет приоритет.

Live Server (`ritwickdey.liveserver`) не устанавливается; вместо него есть Live Preview от Microsoft. Парные HTML/JSX-теги переименовывает сама IDE (`editor.linkedEditing`), поэтому Auto Rename Tag убран: при обновлении он переносится в backup, его настройки удаляются. Подсветка `.env` тоже встроена в Antigravity IDE (`dotenv`), поэтому с 3.13.0 избыточный `mikestead.dotenv` убран и переносится в backup при обновлении. Настройки AI отключены; обычный IntelliSense остаётся.

В 3.0.6 разделены владельцы функций: Prettier форматирует, Oxc запускает Oxlint (с 3.12.0 — в режиме `onSave`, чтобы не конкурировать с IntelliSense при каждом нажатии клавиши; при Auto Save 1000 мс ошибки всё равно появляются через секунду паузы; Oxfmt выключен), Auto Rename Tag менял парные теги (с 16.11.2026 это делает встроенный `editor.linkedEditing`). Встроенная JS/TS-служба предлагает символы и автоимпорты; Path Intellisense отвечает за относительные пути, а npm Intellisense — за имена установленных пакетов. Подсказки внутри строк включены. Проверка CSS/SCSS и ошибки Tailwind включены; стандартные Tailwind-директивы не считаются неизвестными CSS-правилами.

Обновление сохраняет личные цвета, ассоциации файлов и редакторов, исключения поиска/наблюдения, языковые mapping и дополнительные terminal-профили. Настройки проекта по-прежнему имеют приоритет; Workstation Stability сообщает путь конфликтующего файла.

Stability Helper (с 1.3.29) чинит только проверенные версии HTML End Tag Labels, Path Intellisense и Import Cost (Auto Rename Tag убран вместе с расширением). Перед записью проверяет идентификатор, версию и SHA-256 исходника, сохраняет оригинал и повторно проверяет результат. Новая или изменённая вручную версия требует отдельного аудита; она не перезаписывается. Path Intellisense и Import Cost проверены также официальным верификатором подписи Microsoft Marketplace.

Jelly Cursor ставится из своего VSIX (`extensions/jelly-cursor`, upstream MIT 0.0.8, перепакован только ради engine 1.107): он рисует плавный курсор после второго запуска IDE; Calm TypeScript отвечает за мягкую подсветку при наборе.

В 3.0.7 обычное обновление переиспользует исправные совместимые Gallery-пакеты без повторного скачивания. Регистрация, manifest, engine, архитектура, зависимости и основные файлы проверяются локально; повреждённые/несовместимые установки исправляются через официальный download. Это проверка существующей установки, а не новая проверка подписи её издателя. Workstation Stability 1.3.4 также объявляет shortcut-ы как defaults самого расширения, поэтому они действуют и в именованных/новых профилях, где расширение включено; defaults самого helper уступают пользовательским назначениям. При повторной установке installer обновляет управляемые слоты клавиш в Default; этот прежний режим установки не изменён.
